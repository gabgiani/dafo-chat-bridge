# DAFO Chat Bridge

Move a conversation between **GitHub Copilot Chat**, **Claude Code** and **OpenAI Codex** and keep working where you left off. Everything stays on your machine.

- **Sidebar.** Every conversation from the three agents, grouped by agent. Click one to read it, or use **⇄ Pass to…** to send it to another agent or to Markdown.
- **`@bridge` in Copilot Chat.** `@bridge /claude`, `@bridge /codex` and `@bridge /markdown` move the **current conversation**.
- **Status bar.** The **⇄ Bridge** button starts the same flow from anywhere.

Requires Python 3.9+. Full documentation is in the project README.
